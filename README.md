# E-commerce Sales Analysis Dashboard (Power BI)

![Dashboard Screenshot](https://github.com/HimanshuSharma123-a/-E-commerce-Sales-Analysis-Dashboard-Power-BI-/blob/main/power%20bi%20e-commerce%20sales%20dashboard.png)

## Project Overview

This project is an **interactive Power BI dashboard** built to analyze and monitor sales performance for an e-commerce business over time. The dashboard provides key insights across sales, profit, customer behavior, product categories, payment methods, and regional performance. It is designed to help business users and decision-makers quickly identify trends, track KPIs, and make data-driven decisions.

---

## Dataset Summary

- **Source**: E-commerce Sales Data
- **Duration**: 3 Years
- **Records**: Thousands of transaction-level entries
- **Key Fields**:
  - Order Date, Ship Date, Customer Name
  - State, Product Category & Sub-Category
  - Sales Amount, Quantity, Profit, AOV (Average Order Value)
  - Payment Mode

---

## Objectives

- Track overall sales performance using high-level KPIs.
- Analyze monthly profit trends to identify peak and low seasons.
- Understand customer contribution to revenue.
- Evaluate product category & sub-category performance.
- Analyze the most used payment methods.
- Identify top-performing regions/states by revenue.
